# WhatsApp Guard Bot

بوت بسيط لحماية جروبات الواتساب: يحذف أي رسالة فيها رابط أو لفظ ممنوع، ويطرد صاحبها (تحذير أول مرة ثم طرد).

## ⚠️ اقرأ ده قبل أي حاجة

- المكتبة المستخدمة (Baileys) **غير رسمية**: بتحاكي بروتوكول واتساب ويب، مش API رسمي من ميتا. استخدامها فيه مخالفة لشروط استخدام واتساب، وفيه احتمال (مش مضمون، بس وارد) إن الرقم يترمي أو يتقيّد لو واتساب حس إنه بوت.
- **متستخدمش رقمك الشخصي**. استخدم رقم منفصل مخصص للبوت.
- سيب البوت "يدفي" الرقم بالتدريج (استخدام عادي، مش قصف رسائل من أول دقيقة)، وماتخليهوش يبعت رسائل كتير في وقت قصير.
- ثبّت المكتبة بس من المصدر الرسمي: `@whiskeysockets/baileys` من npm/GitHub. فيه فروع (forks) كتير باسم "baileys" أو شبهه على npm بعضها غير موثوق أو معدّل بشكل مشبوه — سيبها.

## المتطلبات

- Node.js نسخة 20 أو أحدث
- رقم واتساب مخصص للبوت (يفضّل يكون أدمن في الجروب عشان يقدر يحذف رسايل ويطرد أعضاء)

## التشغيل

```bash
npm install
npm start
```

هيظهرلك QR code في الترمينال — امسحه من واتساب على موبايلك:
**الإعدادات > الأجهزة المرتبطة > ربط جهاز**

أول ما يتصل، هتلاقي رسالة "✅ البوت شغال ومتصل بواتساب".

## التخصيص

كل الإعدادات في أول ملف `index.js` جوه `CONFIG`:

| الإعداد | الوظيفة |
|---|---|
| `deleteViolatingMessage` | يحذف الرسالة المخالفة تلقائيًا |
| `kickOnViolation` | يفعّل الطرد التلقائي |
| `warnBeforeKick` | تحذير في أول مخالفة، طرد في التانية |
| `allowedGroups` | حط فيها ID الجروبات اللي عايز البوت يشتغل فيها بس (سيبها فاضية = كل الجروبات) |
| `exemptNumbers` | أرقام مستثناة من الفحص (زي الأدمنية) |

### إضافة الألفاظ الممنوعة

الملف `filters/wordFilter.js` فيه قائمة `BAD_WORDS` فاضية عن قصد — الألفاظ بتختلف جدًا حسب اللهجة، فحط فيها كلماتك بنفسك. الفلتر بيطبّع النص تلقائيًا (بيشيل التشكيل، ويقلل الحروف المكررة زي "غبييييي"، ويوحّد الألف/الياء/الهاء) عشان يمسك محاولات الالتفاف البسيطة.

### إضافة روابط ممنوعة إضافية

عدّل الـ regex في `filters/linkFilter.js` لو عايز تضيف نطاقات معينة.

## حاجات ممكن تضيفها بعدين

- لوحة تحكم أو أوامر أدمن (زي `!kick`, `!warn`, `!ban`) عبر رسائل من الأدمن نفسه
- تخزين المخالفات في قاعدة بيانات (SQLite/MongoDB) بدل الذاكرة، عشان متتصفرش لما تعيد تشغيل البوت
- ويب هوك أو لوج خارجي لتسجيل كل حذف/طرد (شفافية للأدمنية)
- استثناء الروابط اللي بيبعتها الأدمن نفسه بشكل تلقائي (موجود جزئيًا عبر `exemptNumbers`)
